# 🚀 Quick Start Guide

Your professional portfolio has been created! Here's how to get it live:

## 📋 Prerequisites

- GitHub account ([Sign up free](https://github.com/signup))
- Git installed on your computer ([Download](https://git-scm.com/))

## ⚡ Quick Steps (5 minutes)

### 1️⃣ Create GitHub Repository
- Go to https://github.com/new
- Name it: **`shivamsharma218.github.io`** (use your actual GitHub username)
- Make it **Public**
- Click **Create**

### 2️⃣ Push Your Portfolio

Open PowerShell/Terminal in your portfolio folder and run:

```powershell
git init
git add .
git commit -m "Initial portfolio"
git remote add origin https://github.com/shivamsharma218/shivamsharma218.github.io.git
git branch -M main
git push -u origin main
```

Replace `shivamsharma218` with your GitHub username.

### 3️⃣ Wait & Visit

- Wait 2-3 minutes
- Visit: https://shivamsharma218.github.io
- Your portfolio is now live! 🎉

## 🎨 Next Steps

### Customize Your Portfolio:

1. **Edit your name/bio** → Open `index.html`, find your name and bio, update it
2. **Update social links** → Find the contact section and add your actual LinkedIn/Twitter links
3. **Add email** → Replace "your.email@example.com" with your actual email
4. **Customize colors** → Edit colors in `style.css` (under `:root`)
5. **Push changes**:
   ```powershell
   git add .
   git commit -m "Updated portfolio"
   git push
   ```

## 🔧 Troubleshooting

| Issue | Solution |
|-------|----------|
| Portfolio not loading | Wait 3-5 minutes, then refresh |
| Changes not showing | Clear cache (Ctrl+Shift+Del), wait a minute |
| Git error | Verify repository name is `username.github.io` |
